# Hebrew style

## Units

- Grams: `350 גר'` — apostrophe, not `גרם` spelled out, inside ingredient lists.
- Temperature: `230°C`. Never Fahrenheit.
- Time: `דק'` in lists, `דקות` in prose.
- Percentages of flour weight: `הידרציה 69%`, `מלח 2.2%`.

## Terminology

Keep Italian technique terms in Italian, with a Hebrew gloss on first appearance in a
recipe, then Italian alone:

| term | first mention |
|---|---|
| incordatura | `incordatura` (מתח גלוטן מלא) |
| pirlatura | `pirlatura` (עיגול הבצק) |
| lievito madre | `lievito madre` (מחמצת קשה) |
| filoncini | `filoncini` (סיגרים קצרים) |
| soffritto | `סופריטו` |
| mantecatura | `mantecatura` (איחוד הרוטב עם הפסטה) |

Hebrew transliteration is fine for terms that have entered Hebrew kitchens (סופריטו,
פוקצ'ה, ריזוטו). Terms that have not — keep in Latin script so they stay searchable.

## Voice

Imperative plural (`הוסיפו`, `לושו`), which is how Israeli recipes read. Not infinitive,
not second person singular.

Warnings go inline where the mistake happens, not in a tips section at the end. "אל
תחזירו לאש" belongs in the cream step, not in a footer nobody reads mid-cook.

## What not to write

No preamble about how wonderful the dish is. No "מתכון קל ומהיר!". The user is cooking,
not browsing.
